Practical 2(a) Pandas

Pandas DataFrame (Student Records)

2a.txt

Create student DataFrame, add new records with `.loc`, drop rows with `.drop()`, filter records (`Age > 22`), and concatenate multiple tables.

import pandas as pd

cols = ['ID', 'Name', 'Age', 'Gender', 'Grade', 'Location']
data = [[1, 'Amit', 21, 'M', 'A', 'Nashik'],
        [2, 'Riya', 23, 'F', 'B', 'Pune']]

df = pd.DataFrame(data, columns=cols)

df.loc[2] = [3, 'Raj', 24, 'M', 'A', 'Mumbai']
df = df.drop(0)

print("Age > 22:\n", df[df['Age'] > 22])

df2 = pd.DataFrame([[4, 'Neha', 22, 'F', 'A', 'Nashik']], columns=cols)
df = pd.concat([df, df2])
print("\nFinal Table:\n", df)

Practical 6 Classification

Logistic Regression Model (Social Network Ads)

6.txt

Binary classification on `Social_Network_Ads.csv`. Computes confusion matrix, TP, FP, TN, FN, Accuracy, Error Rate, Precision, and Recall.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score

url = "https://huggingface.co/datasets/Rodrigopiva/Social_Network_Ads.csv/resolve/main/Social_Network_Ads.csv"
df = pd.read_csv(url)

X = df[['Age', 'EstimatedSalary']]
X = X / X.max()
y = df['Purchased']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25)

model = LogisticRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

cm = confusion_matrix(y_test, y_pred)
tn, fp, fn, tp = cm.ravel()
acc = accuracy_score(y_test, y_pred)

print("Confusion Matrix:\n", cm)
print("TP:", tp, "FP:", fp, "TN:", tn, "FN:", fn)
print("Accuracy:", acc)
print("Error Rate:", 1 - acc)
print("Precision:", precision_score(y_test, y_pred))
print("Recall:", recall_score(y_test, y_pred))
Practical 7 Decision Trees

Simple CART Classification Model (Iris Dataset)

7.txt

Multi-class classification using DecisionTreeClassifier (CART) on Iris dataset with multi-class Confusion Matrix and macro-averaged Precision & Recall.

import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score

iris = load_iris()
X, y = iris.data, iris.target

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25)

model = DecisionTreeClassifier()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

cm = confusion_matrix(y_test, y_pred)
tp = np.diag(cm)
fp = cm.sum(axis=0) - tp
fn = cm.sum(axis=1) - tp
tn = cm.sum() - (tp + fp + fn)
acc = accuracy_score(y_test, y_pred)

print("Confusion Matrix:\n", cm)
print("TP:", tp, "FP:", fp, "TN:", tn, "FN:", fn)
print("Accuracy:", acc)
print("Error Rate:", 1 - acc)
print("Precision:", precision_score(y_test, y_pred, average='macro'))
print("Recall:", recall_score(y_test, y_pred, average='macro'))
